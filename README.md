## 💡 ESP32 Smart Light Control

A team project involving an **ESP32**, web application, and mobile application for remotely controlling LED lights.

### Team

**3 members**

* ESP32 / hardware
* Mobile application
* Web application

I was responsible for the **mobile application**.

### My contribution

* Developed the mobile application using **Flutter**
* Worked on communication between the application and the ESP32 system
* Helped address synchronization issues between the mobile and web interfaces

### The challenge

One of the more memorable problems was keeping the state of the LED synchronized between the ESP32, web application, and mobile application.

A command could be triggered from different interfaces, creating timing and state inconsistencies.

This project taught me that making individual components work is only part of the problem.

Making multiple components **communicate reliably as one system** is another challenge entirely.
